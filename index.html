🎤 نکته برای ارائه‌دهنده

لازم نیست همه کدها را از حفظ بخوانی. اول مفهوم را با مثال روزمره توضیح بده، بعد چند خط کد را نشان بده و در پایان از کلاس بپرس «به نظرتان این کد چه کاری انجام می‌دهد؟» برای هر درس حدود ۲ تا ۳ دقیقه توضیح و پرسش در نظر بگیر.

  • در HTML از تگ‌ها برای مشخص‌کردن نوع محتوا استفاده می‌کنیم.
  • در CSS ویژگی‌ها و مقدارها ظاهر را تعیین می‌کنند.
  • در JavaScript می‌توانیم به رویدادهایی مثل کلیک واکنش نشان بدهیم.
  • سایت خوب علاوه بر ظاهر، باید خوانا، قابل استفاده و قابل دسترس باشد.

🧠 آزمون پایانی کلاس

۲) برای تغییر رنگ پس‌زمینه معمولاً از چه چیزی استفاده می‌کنیم؟

۳) JavaScript چه کاربردی دارد؟

۴) چرا باید سایت را قبل از انتشار آزمایش کنیم؟

جمع‌بندی نهایی ✦

وب‌سایت از چند بخش مکمل تشکیل می‌شود. طراح وب با کنار هم گذاشتن آن‌ها تجربه‌ای روشن و مفید برای بازدیدکننده می‌سازد.

HTML — ساختارعنوان‌ها، متن‌ها، تصاویر، لینک‌ها و فرم‌ها را مشخص می‌کند.
CSS — ظاهررنگ، فونت، اندازه، فاصله و چیدمان را کنترل می‌کند.
JavaScript — رفتاربه کلیک‌ها، ورودی‌ها و رویدادهای کاربر پاسخ می‌دهد.

پیام پایانی: برای ساخت اولین سایت، لازم نیست از همان ابتدا همه چیز را بدانیم. با یک صفحه ساده شروع می‌کنیم، آن را آزمایش می‌کنیم و قدم‌به‌قدم بهترش می‌کنیم.
